About the Artifact

This portfolio showcases the enhancements made to an Android-based Inventory Management System. Originally created in CS 360, the application has been refined to demonstrate mastery in software engineering, algorithmic efficiency, and database management.

Code Review

A walkthrough of the existing code, highlighting planned enhancements and identifying technical debt.

Software Design and Engineering

Focuses on usability, security, and maintainability. Key enhancements include fixing layout responsiveness for tablets, implementing SHA-256 password hashing for security, and creating a compact number formatting utility for better UI readability.

Algorithms and Data Structures

Demonstrates algorithmic efficiency through a predictive ordering system. Implemented a sliding window algorithm to analyze inventory usage rates over time (e.g., per minute) and a custom graph data structure to visualize consumption trends dynamically.

Databases

Showcases advanced database management using SQLite. Enhancements include schema normalization with a new usage_log table, implementing complex aggregation queries for reporting, and ensuring data integrity during inventory updates.
